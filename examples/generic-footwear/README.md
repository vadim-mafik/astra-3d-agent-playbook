# Generic footwear example

This directory shows how the playbook can be applied to a small reference-driven hero asset without tying the workflow to a private production project.

## Example subject

Historically inspired men's urban lace-up ankle boots, circa 1900–1910.

The example assumes these neutral reference paths:

- `references/side.png`
- `references/three-quarter.png`
- `references/front.png`
- `references/back.png`
- `references/pair.png`

The point of the example is not historical research itself. It demonstrates how to turn a visual brief into a bounded art task with clear priorities, review views, and a stop condition.

See [TASK.example.md](TASK.example.md) for a filled task.
