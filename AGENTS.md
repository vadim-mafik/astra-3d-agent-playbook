# Repository agent guidance

This is a **public, generic playbook**. Keep every change safe to publish.

## Repository rules

- Never add private project names, usernames, absolute personal paths, credentials, tokens, private URLs, production logs, or unpublished screenshots.
- Human-facing documentation should read like documentation, not like an agent transcript or a task dump.
- Copyable prompts belong in fenced code blocks under `prompts/`.
- Keep examples generic and self-contained.
- Do not turn the repository into an infrastructure-debugging handbook for one machine or one MCP implementation.
- Astra Art is a visual specialist. The art pass ends at **ART APPROVAL**; export, rigging, optimization, and engine integration belong to a separate technical pass.
- Prefer exact inputs and bounded task packets over broad repository or filesystem discovery.

When changing the custom-agent configuration, keep it valid against the current Codex agent-role format and avoid undocumented keys.
