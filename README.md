# Astra 3D Agent Playbook

Practical workflows, agents and prompts for high-quality 3D asset creation with Astra and Blender MCP.

🇷🇺 Russian version: [README.ru.md](README.ru.md)

## Workflow
cheap preparation → clean Astra High session → Blender MCP → model → viewport/render → critique → revision → repeat → ART APPROVAL → separate technical integration.

Technical validity is not visual success.

## Quick start
Install Blender and compatible MCP; configure Codex; copy the agent and skill; fill [templates/art-task](templates/art-task); run [preflight](prompts/preflight.md); start GPT-6 Astra High; verify MCP; run [art-pass](prompts/art-pass.md); stop at ART APPROVAL; integrate separately.

## Requirements
Codex with Astra, GPT-6 Astra, Blender, compatible Blender MCP, and optional Git.
