# Art pass

Use this after preflight has passed and the asset is ready for a full visual production session.

Copy the block below into the Astra art session.

```text
Make the assigned asset look excellent.

Use the supplied references and task packet as the source of truth.

Work through Blender MCP in the intended Blender scene. Establish the primary form first, then iterate:

REFERENCE -> MODEL -> VIEWPORT/RENDER -> CRITIQUE -> REVISION -> REPEAT

After each meaningful pass, inspect the result and identify the highest-impact visible mismatch. Fix that mismatch before polishing lower-priority details.

Prioritize:
1. silhouette
2. overall proportions
3. construction logic
4. primary and secondary forms
5. material response
6. small details
7. presentation

Do not stop at the first technically valid mesh.
Do not perform engine integration, rigging, LOD work, or unrelated project changes during this pass.

If a required input or Blender MCP connection is missing, report the exact missing dependency and stop instead of broadly exploring.

Stop only when the visual acceptance criteria are satisfied. End at ART APPROVAL.
```
