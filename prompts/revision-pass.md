# Revision pass

Use this when an asset already exists but the result is visually weak or has drifted away from the references.

```text
Inspect the existing assigned asset through Blender MCP and compare it against the supplied references.

Do not rebuild blindly.

Identify the three highest-impact visual problems in the current version. Rank them by effect on silhouette, proportions, construction, and overall read.

Fix the highest-impact problem first, inspect the result again, then continue to the next problem only if it is still relevant.

Repeat the viewport/render -> critique -> revision loop until the asset has materially converged.

Do not add unrelated design features.
Do not use material polish to hide incorrect geometry.
Do not perform engine integration.

Stop at ART APPROVAL or report the remaining visible blockers.
```
