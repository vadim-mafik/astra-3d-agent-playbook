# Acceptance criteria

The art pass is complete only when all required visual checks are satisfied.

- [ ] Silhouette matches the authoritative references.
- [ ] Overall proportions are correct from the required review views.
- [ ] Construction reads as physically/design-wise coherent.
- [ ] Primary and secondary forms are resolved.
- [ ] Materials read correctly at the intended scale.
- [ ] Important seams, joins, fasteners, or other task-specific details are complete.
- [ ] No obvious intersections, floating parts, accidental gaps, or one-sided unfinished features remain.
- [ ] The asset has been reviewed from every view listed in `TASK.md`.
- [ ] Remaining issues, if any, are explicitly documented and accepted.
- [ ] `ART APPROVAL` is explicit.

Technical export/import readiness is evaluated in a separate integration task unless this packet says otherwise.
